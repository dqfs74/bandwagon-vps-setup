## 搬瓦工新手安装教程：从注册到 SSH 登录全流程

### 第一步：注册账号

进官网，点右上角 Register 注册。填姓名、邮箱、密码，还有收货地址（填真实信息，跟税务有关，乱填容易被判定为欺诈然后自动退款）。

注意：注册前建议关掉代理软件，用真实 IP 注册。

### 第二步：选套餐加购物车

👉 [点此进入搬瓦工套餐选择页](https://bit.ly/BanWaGon)

套餐页面选好配置，点 Add to Cart。有些套餐会让你选初始机房，CN2 GIA-E 套餐不用太纠结——购买后在 KiwiVM 后台可以随时免费切换机房，选哪个都行。

### 第三步：结算付款

进购物车，点 Checkout。付款方式支持支付宝、银联、PayPal 和信用卡，选支付宝扫码就行，几十秒完成。

付款成功后会收到一封邮件，里面有 VPS 的基本信息。

### 第四步：进入 KiwiVM 控制面板

登录搬瓦工账号后台 → Services → My Services，找到购买的 VPS，点击 Open KiwiVM 进入控制面板。

KiwiVM 是搬瓦工自己开发的控制面板，功能挺全：

- **Main controls**：开关机、重启
- **Root password modification**：重置 root 密码
- **Install new OS**：一键重装系统
- **Migrate to another DC**：一键迁移机房
- **Snapshots**：创建快照（建议在折腾之前先拍一个）

在 Main controls 页面可以看到 IP 地址和 SSH 端口号。

### 第五步：重置 root 密码，拿到登录凭据

需要先把 VPS **开机**（注意：现在重置密码要求开机状态），然后在 KiwiVM 里点 Root password modification → Generate and set new password。

密码只出现一次，立刻复制保存。忘了没关系，再重置一次就行。

这时候你手里有三样东西：
1. IP 地址
2. SSH 端口号（不是默认的 22，搬瓦工用的是随机高位端口）
3. root 密码

### 第六步：SSH 连接 VPS

**Windows 用户**：推荐用 Termius，免费版够用，跨平台还能同步配置。打开后新建 Host，填 IP、端口、用户名（root）、密码，保存连接就行。

**Mac / Linux 用户**：直接打开终端，命令格式：

bash
ssh root@你的IP地址 -p 你的端口号


输入密码，看到 `[root@xxx ~]#` 这样的提示符，就说明登进去了。不夸张，新手第一次看到这个界面会有点激动。

## 新手最容易踩的几个坑

**坑一：注册信息随便填**。填假地址被识别为欺诈，订单会自动取消退款，但账号也可能被标记，后续麻烦。填真实信息就好，搬瓦工不会拿来邮件轰炸你。

**坑二：SSH 端口用默认 22**。搬瓦工的 SSH 端口不是 22，是随机高位端口，在 KiwiVM 里查。用 22 连不上是正常的。

**坑三：密码没记住**。重置密码的时候，页面只会显示一次新密码，关掉就看不到了。重置前先开个文本编辑器准备复制。

**坑四：随便折腾完没有快照**。第一次上手可能会搞坏配置，在 KiwiVM 拍个快照只要几分钟，出问题直接恢复，省去重装的麻烦。
